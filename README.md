# LifeOS в цифрах

Доска для инвесторов. Сайт обновляется сам раз в 15 минут.

- `index.html` страница доски, раз в минуту забирает `stats.json`.
- `stats.json` цифры. Пользователи, возврат и реклама правятся здесь вручную; посетители, страны, карта и график обновляются из Яндекс Метрики.
- `build_stats.py` сборщик, запускается облачным запуском GitHub (`.github/workflows/update.yml`).
- Секрет `METRIKA_TOKEN`: OAuth-токен Яндекс Метрики с правом чтения (счётчик 113327643). Без него сайт показывает цифры из `stats.json`.
